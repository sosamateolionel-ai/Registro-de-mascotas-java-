# Mascota

## Descripción

Programa desarrollado en Java que representa una mascota mediante su nombre, raza y edad. Permite aumentar la edad de la mascota y verificar que su valor sea válido.

## Funcionamiento

El programa utiliza una clase `Mascota` con tres atributos: `nombre`, `raza` y `edad`.

El método `AumentarEdad()` incrementa la edad de la mascota en uno mediante el operador `++`. Luego utiliza una estructura condicional `if-else` para verificar que la edad sea mayor a cero.

En el método `main` se crean dos objetos `Mascota` con diferentes datos. Se muestran sus características y se utiliza el método `AumentarEdad()` para modificar y comprobar la edad de cada mascota.
